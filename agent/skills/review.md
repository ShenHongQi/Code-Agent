请审查当前工作区的代码变更（使用 view_diff 或 git diff），分析以下方面：

1. **正确性**：是否有逻辑错误或 bug
2. **安全性**：是否有安全隐患（注入、敏感信息泄露等）
3. **可维护性**：代码风格、命名、结构是否清晰
4. **性能**：是否有明显的性能问题

{args}

## 输出格式

对每个发现的问题：
- 引用具体的文件和代码行
- 说明问题类型（bug / 安全 / 风格 / 性能）
- 给出具体的修改建议

最后给出总体评价和优先修复建议。
