## 要求

1. 先阅读代码理解功能和接口
2. 生成清晰、准确、实用的文档
3. 包含以下内容（按需）：

   - **快速开始**：最简使用示例
   - **API 说明**：函数签名、参数、返回值

   - **注意事项**：常见陷阱和限制
4. 使用 Markdown 格式
5. 放在合适的位置（README.md、docs/ 目录、或代码内 docstring）
