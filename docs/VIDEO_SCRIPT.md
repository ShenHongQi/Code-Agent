# 演示视频脚本（≤2 分钟）

> 总时长控制在 1:50 左右，留 10s 余量。全程录屏 + 语音旁白。
> 建议用 Windows Terminal (WSL2) 全屏录制，字体 ≥16pt 确保清晰。
> 可剪辑、可加速（LLM 流式输出部分建议 2-4x 加速）。

---

## 第一幕：启动与介绍（0:00 – 0:20）

**画面**：在一个空的项目目录下启动 megumin

```bash
cd ~/demo-project

```

**旁白**（叠加在启动 banner 展示上）：

> 包括对话管理、工具系统、上下文压缩、权限控制等。"

**展示要点**：
- MEGUMIN 像素字 banner（视觉吸引力）

## 第二幕：核心能力演示 — 完成一个真实编程任务（0:20 – 1:20）

### 任务选择建议（三选一，推荐方案 A）

#### 方案 A：用 /goal 自动完成一个 Flask TODO API（推荐）

**旁白**：
> "我来演示用 goal 模式让它自主完成一个完整任务。"

**输入**：
```
/goal 用 Flask 实现一个 TODO API，支持增删改查，带 SQLite 持久化，写好后运行测试验证
```

**预期 agent 行为**（加速播放）：
1. 创建 `app.py` — 调用 `write_file` 工具
2. 创建 `test_app.py` — 调用 `write_file` 工具
3. 安装依赖 — 调用 `bash` 工具执行 `pip install flask`
4. 运行测试 — 调用 `bash` 工具执行 `python -m pytest`
5. 测试失败 → 自动修复 → 再次运行 → 测试通过
6. 自主判断目标达成，结束迭代

**旁白叠加在过程上**（按顺序）：
> "它先规划了实现方案，然后开始创建文件。"
> "工具调用会经过权限系统审批，文件操作自动放行，shell 命令需要确认。"
> "（指向权限弹窗）这里可以看到交互式的权限确认。"
> "测试没通过，它自动分析了错误原因并修复。"
> "目标达成，自动停止。整个过程无需人工干预。"

**展示要点**：
- ✅ 自主多轮迭代（goal 模式核心亮点）
- ✅ 工具调用：write_file、bash、edit_file
- ✅ 权限系统（交互式箭头选择菜单）
- ✅ 错误自愈能力
- ✅ 循环终止条件（自主判断达成）
- ✅ 流式输出 + spinner 状态指示

## 录制技巧

1. **加速策略**：LLM 流式输出（token 一个个出来的部分）加速 3-4x，人的操作和关键画面保持原速
2. **字体**：≥16pt，推荐 JetBrains Mono 或 Cascadia Code
3. **终端配色**：用 Windows Terminal 默认深色主题即可，megumin 自带 ANSI 配色
4. **分辨率**：1920×1080，全屏终端
5. **提前准备**：
   - 确保 API Key 已配置（不要在视频中出现配置过程）
   - demo-project 目录提前清空
   - 网络稳定（LLM 请求不要超时）
   - 提前跑一遍确认流程顺畅
6. **剪辑点**：
   - 等待 LLM 响应时可以剪掉
   - 多个工具调用之间可以跳切
   - 保留关键的"思考→决策→执行→结果"链条
7. **字幕**（可选）：如果语速快或担心听不清，加字幕会更专业
